CARA UPLOAD KE GITHUB (github.com/dzurrihensem/ONESTOPCENTRE)
1. Buka repo > Add file > Upload files
2. Seret SEMUA isi folder S1STEN-MASTER (bukan folder itu sendiri) ke dalam kotak upload.
   Pastikan folder "public" (termasuk "public/icons") dan "src" ikut sekali.
3. Commit changes. Netlify akan build & deploy automatik.

SELEPAS DEPLOY
- Peranti yang dapat skrin putih: buka sistendz.netlify.app, tutup & buka semula 1-2 kali.
- Untuk ikon baharu: buang app S1STEN lama di peranti, kemudian install semula.
